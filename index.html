AI-powered usability evaluation

Visual usability analysis grounded in Nielsen’s heuristics.

HeuriVision analyzes screenshots of web interfaces with Gemini Vision API and compares two prompt engineering strategies: a naive baseline prompt and a structured heuristic-based prompt.

Research logic

What the prototype evaluates

01

Naive prompting

A simple baseline prompt asks the model to identify what is wrong with the interface. This strategy is used as a comparison point.

02

Structured heuristic prompting

The model receives Nielsen’s 10 Usability Heuristics and must return issues in a structured, measurable format.

03

Automatic metric calculation

Outputs are evaluated using heuristic coverage, issue specificity, potential false positive rate, and consistency score.

Bachelor thesis scope

Client-side web application without backend

The application runs fully in the browser, uses localStorage for experiment history, and communicates directly with Gemini Vision API. This makes the prototype easy to deploy on GitHub Pages and suitable for controlled experimental testing.
